# Component Tools Reference

This section provides reference information for the core Kubernetes components.

## Components

-   **kube-apiserver**: The front-end for the control plane.
-   **kube-scheduler**: The component that assigns pods to nodes.
-   **kube-controller-manager**: Runs the built-in Kubernetes controllers.
-   **kubelet**: The agent that runs on each worker node.
-   **kube-proxy**: The network proxy that runs on each node.
